### 🚀 Sobre mí

- 💼 Construyo **EasyStock**, un ERP SaaS de inventario, ventas y caja para pequeñas y medianas empresas.
- 🏗️ Diseño APIs REST con **Spring Boot**, bases de datos **multi-tenant** (una base por empresa) y microservicios que se comunican con **OpenFeign** y **Resilience4j**.
- 🔐 Trabajo con seguridad basada en **JWT**, sesiones móviles con refresh token, límite de intentos e idempotencia con **Redis**.
- ⚙️ Automatizo despliegues con **Docker**, **Jenkins** y **GitHub Actions**.
- 🌱 Ahora mismo estoy aprendiendo más sobre microservicios, observabilidad y React.

### 📦 Proyecto destacado: EasyStock

ERP en la nube para gestionar inventario, compras, ventas, caja, reportes y facturación de varias empresas desde una sola plataforma.

| Módulo | Descripción | Stack |
|---|---|---|
| **EasyStock-Back** | API principal del ERP: productos, lotes y seriales, bodegas y sedes, movimientos, caja, reportes en PDF, permisos por rol y API para la app móvil. | Java · Spring Boot · PostgreSQL multi-tenant · Redis · Flyway · JWT |
| **easyStock-plan-empresa** | Microservicio de planes y alta de empresas: registra al cliente, crea su base de datos en el ERP y envía los correos de bienvenida. | Java 17 · Spring Boot 3 · OpenFeign · Resilience4j · Spring Mail |
| **easystock-front** | Aplicación web del ERP. | React · TypeScript · Tailwind CSS |
