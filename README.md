## 💻 Proyectos destacados

### EasyStock ERP

Sistema ERP para la gestión comercial de empresas, desarrollado con una arquitectura empresarial basada en Spring Boot y tecnologías frontend modernas.

- Gestión de productos, compras, ventas e inventario.
- Arquitectura modular con servicios independientes.
- Multitenancy para separar la información de las empresas.
- Seguridad basada en autenticación y autorización mediante JWT.
- Gestión de inventario, movimientos y costos.
- PostgreSQL, Docker y despliegues en servidores Linux.

**Tecnologías:** Java, Spring Boot, Spring Security, PostgreSQL, React, Docker y Nginx.
